## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
cd frontend && npm install && cd ..
```

## Run order (Python, from the project root)

```bash
python scripts/generate_mock_data.py
python scripts/outcome_model.py
python scripts/treatment_model.py
python scripts/estimate_effects.py
python scripts/crossfit_ite.py
python scripts/plot_qini.py
python scripts/refute_model.py
```

## Dashboard

```bash
cd frontend
npm start
```

Open http://localhost:3000, then load `data/processed/ite_scores_crossfit.csv` in the scores card.

## Results

See `docs/results.md` for the headline estimates, the DoWhy audit, and the ranking evidence.

## Data

`data/mock/` and `data/processed/` are generated by the run order above and are not committed.
